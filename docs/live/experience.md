# Continuous inspection experience

The live workspace preserves the video DOM element and the inventory column across prepare, pairing, connected, scanning, saving and saved states. Session creation replaces the URL without remounting the workspace. Source evidence and manual markers appear in the same viewing area; returning restores the camera view. Inventory selection highlights its current tracked box. Camera access is requested only on the phone route after explicit interaction.

Controls follow real local recording state and persisted session state. Saving is shown only after the server finishes; an allocated inspection ID is not treated as success. Pixel activity represents a pending operation, elapsed time is real and upload percentage comes from acknowledged chunks. No invented staged progress. Reduced-motion CSS disables motion. Saved record history remains a separate destination accessible after saving.
